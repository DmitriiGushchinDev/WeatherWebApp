# 🌦 WeatherApp

WeatherApp is an open-source backend service that provides real-time and historical weather data.  
It is designed as a learning project and a demonstration of building production-style APIs with FastAPI.

---

## 🚀 Features
- Real-time weather data fetched from **OpenWeatherMap API**
- RESTful endpoints built with **FastAPI** (async, high-performance)
- **PostgreSQL** integration for storing and querying weather history
- **Docker Compose** setup for easy local deployment
- Auto-generated API docs with **Swagger (OpenAPI)**
- Unit testing with **pytest**

---

## 🛠 Tech Stack
- **Backend Framework**: FastAPI
- **Database**: PostgreSQL
- **API Client**: OpenWeatherMap
